LATEST v0.4.2

Cloudflare Turnstile Bot Protection, Dynamic Menu Backgrounds & QUIC Tunnel Stability

September 14, 2026
  • Cloudflare Turnstile Enforcement: Enforced Cloudflare Turnstile verification on web authentication and account creation (/api/login). Client-side validation in login.js strictly requires challenge completion before submission with clear inline alerts, backed by cryptographic server verification via Cloudflare siteverify.
  • Dynamic osu! Seasonal Backgrounds: Completely overhauled the seasonal backgrounds engine in src/server/backgrounds.rs to dynamically discover and serve all uploaded images in data/backgrounds/. Eliminated hardcoded filenames and 404 dead links, enabling the osu! client to rotate through all uploaded backgrounds on the main menu.
  • Cloudflare Tunnel 502 Bad Gateway Resolution: Eliminated occasional 502 connection drops caused by HTTP/2 over TCP multiplex stream resets. Upgraded tunnel protocol to QUIC over UDP with IPv4 edge selection (--edge-ip-version 4), raising file descriptors to 4096 with watchdog recovery loops.
  • CSRF Security & LAN / Origin Whitelisting: Hardened CSRF middleware with flexible domain and origin verification for LAN, localhost, and proxy host headers. Changed rejection responses to structured JSON ApiResponse to prevent client-side script crashes.
  • Security Hardening & Profile Markdown Enhancements: Upgraded password security with bcrypt hash verification, pseudonymized hardware ID fingerprints, implemented session revocation tables, and expanded the profile "About Me" engine with full GitHub-flavored markdown and safe HTML tag passthrough.
  • Fail2Ban Integration & Relaxed Rate Limits: Integrated Fail2Ban jails and Nginx filter rules for brute-force mitigation, while relaxing rate limits across all tiers (General 3600 RPM, Bancho 3600 RPM, Direct 1800 RPM, Sensitive 180 RPM) for a fluid player experience.

Early Preview 2026/09/13 - v0.4.0

osu!fx Multi-Client Support, Beatmap Proxying & Dynamic Domain Routing

September 13, 2026
  • Dedicated osu!fx Client Architecture: Isolated connection and handshake handling for the osu!fx client via src/server/osufx.rs; implemented /web/osu-checktweets.php and /web/osu-error.php, completely eliminating NotFound errors in network logs.
  • Direct Download & Streaming Proxy: Implemented /d/{set_id} beatmap download endpoint with direct proxying and chunked streaming from mirror APIs, bypassing .NET HTTP-to-HTTPS redirect restrictions and standardizing .osz file delivery.

Automatically resolves public base URLs (e.g. hatsuneakiko.io.vn or 127.0.0.1:5000) for post-match client charts.
  • Integrated rustpp (oppai-ng) PP Engine: Integrated the pure Rust rustpp library from GitLab as the official Star Rating and Performance Points calculation engine.
v0.3.1

Performance Points (PP) & Accuracy Recalculation Engine

September 11, 2026
  • Algorithmic PP Calculation: Implemented native PP calculation for all 4 osu! game modes (Standard, Taiko, Catch the Beat, osu!mania) and Relax (RX), evaluating star rating, non-linear combo scaling, accuracy curves, miss penalties, and mod multipliers (HD, HR, DT, FL, EZ, HT, NF, RX).
  • Official osu! Weighted Decay: User profiles now compute total PP (Σ ppi × 0.95i) and weighted accuracy (Σ (acci × 0.95i) / Σ 0.95i) across unique top plays, including playcount bonus PP.
  • Real-Time Client Submission Charts: Beatmap submission now populates dynamic ppBefore, ppAfter, accuracyBefore, and accuracyAfter, animating in-game ranking screens with live score progression.
  • Bancho Stats Broadcast Fix: Updated CHO_USER_STATS packet broadcasting to transmit non-zero accuracy and integer PP values, eliminating the bug where clients permanently displayed 0.00% accuracy and 0pp.
  • Database Schema Evolution: Added pp and accuracy to scores, stars and max_combo to beatmaps, with automated retroactive recalculation on startup.
  • Leaderboard & Profile Enhancements: Global rankings now order players by PP descending with ranked score tie-breakers. Recent plays table on the web profile and bot commands (!recent, !stats) now display real PP and Accuracy.

v0.1.0

Initial Architecture & Bancho Protocol

September 9, 2026
  • High-Performance Rust Core: Asynchronous server built on Tokio, Axum, and SQLx SQLite with WAL journaling and memory caching.
  • Bancho Packet Serialization: Complete implementation of the osu! Bancho binary protocol (v19) including ULEB128 encoding and packet multiplexing.
  • Multi-binary & Modular Architecture: Configurable as a single all-in-one process or split into independent gateway, bancho, and web services.
  • ARM64 & Termux Compatibility: Tested and optimized for ultra low-resource hosting on Linux and Android Termux environments.
